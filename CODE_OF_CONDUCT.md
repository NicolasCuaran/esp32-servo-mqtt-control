# Código de Conducta

Este proyecto sigue una versión resumida del
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Compromiso

Nos comprometemos a que la participación en este proyecto sea una experiencia
libre de acoso para todas las personas, sin importar edad, identidad o
expresión de género, orientación sexual, discapacidad, etnia, nivel de
experiencia, nacionalidad, apariencia o religión.

## Comportamiento esperado

- Lenguaje respetuoso e inclusivo.
- Crítica constructiva y enfocada en el código.
- Aceptar feedback con apertura.
- Empatía con otros miembros de la comunidad.

## Comportamiento inaceptable

- Acoso público o privado.
- Comentarios despectivos o ataques personales.
- Publicar información privada de terceros sin permiso.

## Aplicación

Los responsables del proyecto pueden eliminar, editar o rechazar comentarios,
commits, código, ediciones de wiki, issues y otras contribuciones que no se
alineen con este Código de Conducta.

Para reportar incidentes, abre un issue privado o contacta al mantenedor.
